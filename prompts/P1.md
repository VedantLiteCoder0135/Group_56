# P1: AI prompts

## Prompt 1: Candidate assignment generator

Implement only `candidate_solution/1` for Q1 in SWI-Prolog 9.x. Generate every assignment of Alex, Ben, Carla and Dana in that order, using each department, language and project exactly once. Use `permutation/2`; do not implement clues, counting or output yet.

## Prompt 2: Clue checking

Implement only `clue/2` for Q1 with eight numbered clauses, one for each clue in the assignment. Each clause must check its clue against a fully instantiated `candidate_solution/1` result. Keep the generator unchanged, and do not implement solving, counting, output or clue 9.

## Prompt 3: Filter valid assignments

Implement only `valid_solution/1` for Q1. Generate a complete candidate and require all eight existing `clue/2` predicates to succeed. Do not add printing, counting, or clue 9.

## Prompt 4: Print a solution

Implement only `main/0` for Q1. Print the first `valid_solution/1` as exactly four lines in Alex, Ben, Carla, Dana order, formatted `Name = [department, language, project]`. Do not print anything on load or add initialization directives.
