# P2: AI prompts (verbatim)

## Prompt 1

Implement expression_tree/2 in 56_q2.pl using SWI-Prolog 9.x. Generate binary arithmetic expression trees with +, -, *, / while preserving the input number order. Support all possible parenthesizations and use only the permitted libraries.

## Prompt 2

Implement evaluate_tree/2 to recursively evaluate arithmetic expression trees using integers. Allow negative results, reject division by zero and non-exact division, and preserve the existing code.

## Prompt 3

Implement format_tree/2 to convert expression trees into canonical SWI-Prolog strings. Follow the assignment's precedence and associativity rules, inserting parentheses only when required. Do not add spaces or modify existing predicates.

## Prompt 4

Implement generate_equation/2 by splitting the input list into two nonempty consecutive parts, generating and evaluating expression trees, and returning a canonical equation string when both sides have equal integer values. Fail safely for invalid inputs.

## Prompt 5

Implement all_equations/2 using findall/3 and sort/2 to return all valid equations as a sorted, duplicate-free list. Reuse generate_equation/2 without changing its behavior.

## Prompt 6

Implement count_equations/2 to return the number of unique valid equations using all_equations/2. Return zero when no valid equations exist.

## Prompt 7

Create tests/q2_tests.pl using SWI-Prolog's plunit framework. Test the assignment examples, number ordering, operator precedence, exact division, division by zero, duplicate removal, and empty or single-element inputs. Do not modify the implementation.

## Prompt 8

Review the failing input_order_preserved test in tests/q2_tests.pl. Correct its expected canonical formatting without changing the implementation or weakening the number-order verification.
